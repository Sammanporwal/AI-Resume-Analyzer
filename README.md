# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer built using Flask and Python.

## 🚀 Features

- Resume Upload (.pdf, .doc, .docx)
- Resume Score Analysis
- Skill Gap Analysis
- Career Recommendations
- Interview Questions Generation
- Professional PDF Report Download
- Modern Dashboard UI

## 🛠️ Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript

## ⚙️ Installation

```bash
git clone https://github.com/Sammanporwal/AI-Resume-Analyzer.git
cd AI-Resume-Analyzer

pip install -r requirements.txt

python app.py
```
